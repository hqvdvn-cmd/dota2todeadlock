# Проверка дистрибутива 2026.10.17

Срез ресурсов: 17 октября 2026. В локальном Steam-манифесте на момент публикации указан build ID **25999968**. Это метка исходной установки; совпадение номера само по себе не заменяет проверку содержимого и поведения мода.

## Исправление установщика — 18 октября 2026

По сообщению о `Unable to read default keybinding configuration (user_keys_default)` обнаружена ошибка настройки чистой установки: прежний скрипт добавлял первый Game-путь addons без явных Mod/Write. Комментарии Valve в gameinfo.gi указывают, что при отсутствии этих ключей MOD и DEFAULT_WRITE_PATH выводятся из первого Game-пути. На исходном компьютере это маскировалось уже полной конфигурацией мод-менеджера.

Исправленный `--enable-addons` добавляет недостающие Mod/Write для citadel/core, не меняя остальных строк. Повторная установка ремонтирует конфигурацию и при уже установленных совпадающих VPK. Удаление тоже исправляет старую неполную конфигурацию. Полные существующие настройки сохраняются побайтно.

`python -m unittest discover -s tests -v`: **21 тест прошёл**. Новые сценарии сначала воспроизвели шесть сбоев на прежнем коде, затем прошли после исправления. Проверены чистая конфигурация, повторная установка, удаление, комментарии, кавычки, BOM/CRLF, сохранность копии и доступность стандартного файла по документированным правилам MOD. Последняя проверка моделирует правила поиска файлов; это не запуск движка. Запуск на компьютере сообщившего об ошибке пользователя ещё не подтверждён.

Сверка с первичным кодом мод-менеджера: [MODDED_SEARCH_PATHS](https://github.com/deadlock-mod-manager/deadlock-mod-manager/blob/main/apps/desktop/src-tauri/src/mod_manager/game_config_manager.rs). Игровые пакеты и их хеши не изменены.
