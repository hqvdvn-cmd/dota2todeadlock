# Хэндoф: поставить и откатить мод

## Задача и ограничения

Это готовый дистрибутив Dota-иконок и эффектов для Deadlock на Windows. Сначала прочитай README и manifest.json. Уточни у владельца путь игры и желаемое действие, если они не указаны. Команда владельца установить или удалить мод разрешает соответствующую операцию; повторное подтверждение той же операции не требуется.

Магазин и сетки героев отменены владельцем и удалены. Не добавляй их, не запускай редактор и не устанавливай pak11/pak12. Перенос моделей героев отложен. Пять чужих скинов и фиксы их камер не входят в этот репозиторий; существующие пакеты пользователя нужно сохранить.

Не публикуй локальные журналы, резервные копии, пути пользователя и конфигурацию мод-менеджера. Не устанавливай SDK и сторонние инструменты: для готовых пакетов хватает Python 3.10+ и Windows PowerShell.

## Контракт файлов

| Пакет | Содержимое |
| --- | --- |
| pak06_dir.vpk | Иконки v12: 86 предметов, 133 текстуры; Inhibitor — Skadi + Enfeeble + Mage Slayer тремя отдельными частями |
| pak07_dir.vpk | Принятый Counterspell: оболочка и обод Антимага |
| pak08_dir.vpk | Принятый Refresher: зелёная спираль |
| pak09_dir.vpk | Shiva, красная Arctic Blast, красный Frostbite без проекции и визуальные привязки пассивных барьеров |

Точные SHA-256 и размеры — в manifest.json. pak09/pak10 связаны визуальными привязками; для полной установки нужны оба. Имена pak06–pak10 зарезервированы только для этого дистрибутива: совпадение имени чужого файла не делает его нашей собственностью.

## Перед изменением

1. Найди настоящую папку `Deadlock\game\citadel` через Steam. Проверь наличие `gameinfo.gi` и базового `pak01_dir.vpk` **в citadel**, не в addons.
2. Убедись, что игра и менеджер закрыты. Если работают — попроси закрыть; не завершай игру насильно. Скрипт проверяет процессы до записи.
3. Зафиксируй список и хеши существующих `addons\*.vpk`, `.dmm.json` и `gameinfo.gi`. Не печатай содержимое приватной конфигурации в публичный журнал.
4. Проверь manifest.json и SHA256SUMS.txt. Выполни `python scripts/manage.py install --game-dir "<путь к citadel>"` без `--apply`.
5. При конфликте останови установку. Выясни происхождение занятого файла; не перезаписывай и не перенумеровывай вслепую. Изменение или перенос чужого мода требует отдельного решения владельца.

## Установка

Из корня репозитория:

```powershell
python scripts/manage.py install --game-dir "<путь к citadel>" --apply
```

Используй `--enable-addons` при установке и исправлении конфигурации. Флаг добавляет недостающую строку загрузки и явные `Mod`/`Write` для `citadel` и `core`, сохраняя прежний gameinfo.gi. Без явных маршрутов Source 2 выводит MOD/DEFAULT_WRITE_PATH из первого Game-пути; если это addons, запуск может завершиться ошибкой `Unable to read default keybinding configuration (user_keys_default)`. Повторный запуск исправляет и прежнюю неполную установку без перекопирования совпадающих VPK. Не копируй конфигурацию с чужого компьютера.

Сохрани путь `backup` и локальный receipt.json. Повторно сравни пять установленных пакетов с manifest.json и хеши остальных файлов со снимком. Не выдавай файловые проверки за игровую приёмку.

## Запуск после сброса загрузки

Для уже установленной текущей версии используй:

```powershell
python scripts/manage.py launch --game-dir "<путь к citadel>" --apply
```

`launch` использует проверку и восстановление SearchPaths из установщика, сохраняет копию изменённого gameinfo.gi и передаёт ОС фиксированный URI `steam://run/1422450`, как Steam-запуск DMM после применения профиля. Без `--apply` только просмотр; Steam не открывается. Команда требует пять пакетов текущего дистрибутива и отказывает при отсутствующем или изменённом файле. После удаления она не устанавливает мод заново. Ошибка открытия Steam не отменяет уже сохранённую исправную конфигурацию; устрани ошибку Steam и повтори запуск.

Проверку целостности Steam команда не вызывает. До запуска дождись завершения обновлений игры. Если Steam начал обновление после передачи URI, дай ему закончить, закрой игру и повтори команду. Постоянного наблюдения, блокировки gameinfo.gi и записи при работающей игре нет. Нельзя обещать защиту от будущих сбросов или совместимость ресурсов после патча. Какой процесс сбросил настройку у друга, не установлен; подтверждено только, что VPK сохранились.

При обновлении самого мода сначала удали предыдущую версию скриптом из её сохранённой папки, затем установи новую из отдельной папки. Новая версия намеренно не перезаписывает пакет старого выпуска с другим хешем. Не отключай эту защиту ради обновления.

## Откат

```powershell
python scripts/manage.py uninstall --game-dir "<путь к citadel>"
python scripts/manage.py uninstall --game-dir "<путь к citadel>" --apply
```

Перед удалением скрипт копирует наши пакеты в `.local\backups` вне игры. Проверь, что pak06–pak10 отсутствуют, а чужие файлы и `.dmm.json` сохранились. Строка загрузки addons остаётся; это ожидаемо. Если прежний установщик оставил её без явных Mod/Write, удаление также дополняет эти маршруты с резервной копией, чтобы не оставить ошибку клавиш. Уже полная конфигурация не меняется. Для возврата нашего мода используй `install`.

Если пакеты изменились, автоматическое удаление откажется. Сначала сравни файлы с исходным дистрибутивом и журналами владельца; не удаляй неизвестные данные. Если дистрибутив повреждён, возьми чистую копию того же коммита. При невозможности запуска Python допустим ручной вынос только файлов с подтверждёнными хешами в резервную папку за пределами игры.

Не восстанавливай всю папку addons или старый gameinfo.gi поверх новых настроек. Не используй Steam Verify как первый способ удалить наш мод: пользовательские addons нужно убрать адресно.

## Игровая проверка

- Магазин и выбор героев должны оставаться штатными. Иконки доступны в магазине и инвентаре, номера тиров различимы.
- Counterspell: компактная прозрачная оболочка с ободом; пропадает после парирования.
- Refresher: короткая зелёная спираль без зависших частиц.
- Cold Front: обычная волна Shiva. Arctic Blast: красная волна и красные кристаллы Frostbite на цели без чёрных рамок.
- Grit — голубой Pavise; Guardian Ward и Weapon Shielding — золотой; Reactive Barrier — золотой; Divine Barrier и Indomitable — красный. Проверять только реально доступные срабатывания, перечислить непроверенные.
- При откате те же предметы возвращаются к штатным ресурсам, если их не переопределяет другой мод.

## После обновления игры

Смена Steam build ID сама по себе не требует удаления pak09/pak10 или частичной установки мода. pak09 переопределяет `scripts/abilities.vdata_c`, поэтому сначала проверь этот ресурс в **основном** `citadel/pak01_dir.vpk`, без подстановки версии из addons. Эталонный SHA-256 указан в `manifest.json → compatibility_checks → scripts/abilities.vdata_c`. Сравнение хеша самого мод-пакета эту проверку не заменяет.

- Если штатный ресурс совпадает с эталоном, пересобирать его только из-за нового номера сборки не требуется. Выполняй запрошенную полную установку или обновление по инструкции. Затем проверь запуск и эффекты; совпадение одного ресурса не доказывает совместимость всех остальных ресурсов.
- Если штатный ресурс изменился, сравни определения и перенеси визуальные изменения на новую базу перед утверждением о совместимости pak09. Инструменты пересборки в готовый дистрибутив не входят. При их отсутствии сообщи точное ограничение. Предложить временное отключение пакетов можно как вариант владельцу; выполнять его можно только по его выбору.
- Если получить штатный ресурс не удалось, обозначь совместимость как непроверенную. Не выдавай отсутствие проверки за доказанную поломку или требование хэндoфа убрать эффекты.

Сохраняй согласованный состав мода, пока владелец не выбрал его изменение. При воспроизводимом сбое сначала собери текст ошибки и установи затронутый пакет. При согласованном отключении pak09/pak10 перемещай только подтверждённые файлы в резервную папку; команда `launch` текущего полного дистрибутива откажется при их отсутствии. Не обходи эту проверку молча.
